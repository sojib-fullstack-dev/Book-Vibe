# 📚 Book Vibe

Book Vibe is a simple book management website built with Next.js.

## 🚀 Features

- 📖 Browse books
- 🔍 View book details
- 📚 Read Books list
- ❤️ Wishlist
- 🔃 Sort books by rating, pages, and year
- 📱 Responsive design

## 🛠️ Technologies

- Next.js
- TypeScript
- Tailwind CSS
- DaisyUI
- React Context API

## ▶️ Run Locally

```bash
npm install
npm run dev
